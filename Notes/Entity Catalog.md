# Entity Catalog

An index of reusable Entity scripts, scenes and templates in Comedot's shared library. Detailed documentation is inside each Entity's `.gd` script. Entities are generally "scaffolding" only; specialized gameplay behavior is provided by Components: see `Components Catalog.md`


* AnimatedSpriteEntity: AnimatedSprite2D scene with the Entity script and `sprite` set to the root node. Use when the Entity's primary visual should be an AnimatedSprite2D.
* AreaEntity: Area2D scene with the Entity script, `area` set to the root node, and a CollisionShape2D child. Use when the Entity itself should be an Area2D.
* CharacterBodyEntity: CharacterBody2D scene with the Entity script, a CollisionShape2D child, and CharacterBodyComponent already added. Use for physics-driven characters and objects.
* Entity: Core Entity script and default Node2D scene. Manages component installation, lookup, lifecycle notifications, cached primary area/body/sprite/camera shortcuts, and deletion helpers.
* PlayerEntity: Entity subclass for player-controlled characters. Adds player group/GameState registration and common component shortcuts; keep game-specific behavior in components.
* PortalEntity: Node2D scene with Entity script and PortalInteractionComponent. Use as a reusable portal, door, or teleporter interaction scaffold.
* RigidBodyEntity: RigidBody2D scene with the Entity script and a CollisionShape2D child. Use for physics objects controlled primarily by Godot rigid-body simulation.
* SpriteEntity: Sprite2D scene with the Entity script and `sprite` set to the root node. Use for simple visual Entities whose root should be a Sprite2D.
* TurnBasedEntity: Entity subclass and Node2D scene for turn-based gameplay. Registers with TurnBasedCoordinator, delegates begin/execute/end phases to TurnBasedComponents, and can act once every configurable number of game turns.
* TurnBasedPlayerEntity: TurnBasedEntity subclass for player-controlled turn-based characters. Adds player/GameState hooks, turnBased group membership, and common component shortcuts.
